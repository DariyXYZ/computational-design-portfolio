Will it actually pour?

A casting-feasibility checker that flags misrun risk for a given alloy before a mould is cut, run alongside the panel-nesting engine.

Grasshopper · Casting simulation

Problem

Complex cast-metal connectors and nodes can look fine in a 3D model and still fail to fill completely during casting, a defect that's expensive to discover after the mould is already cut.

Method

A casting-feasibility checker that models pour behavior for a given alloy and flags geometry where misrun risk is high, run early enough in the design process to change the geometry instead of the casting.

Misrun-risk heatmap on a node

Code

Internal tool, not yet published.

Validation

Checked against known problem geometries (thin sections, sharp internal corners) where misrun is a documented risk for the alloys involved.

Result

Used alongside the panel-nesting engine so a design's fabricability is checked at the same stage as its geometry, not discovered afterward.
